# Image Assets Required

Please add the following images to the `public/images/` folder:

## Required Images:

1. **hero-defenders.jpg** (1920x1080px or larger)
   - Two Land Rover Defenders on dramatic background
   - Should be high-quality, atmospheric shot
   - Will be used as full-screen hero background

2. **stonehenge.jpg** (800x600px or larger)
   - Image of Stonehenge or similar British heritage landmark
   - Used in the Restoration Philosophy section

## Temporary Solution:

For now, you can use placeholder images from:

- Unsplash: https://unsplash.com/s/photos/land-rover-defender
- Pexels: https://www.pexels.com/search/land%20rover/
- Or any high-quality automotive photography

Download the images and save them with the exact filenames listed above in this directory.

## Image Optimization Tips:

- Use JPG format for photographs
- Recommended size: 2000px wide max
- Compress images before adding (max 2-3MB per image)
- Next.js will automatically optimize them further
